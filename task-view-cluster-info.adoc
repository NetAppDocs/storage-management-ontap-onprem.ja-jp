= クラスター情報と契約の詳細を表示する
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
NetApp Consoleから容量情報とライセンス情報を直接表示できます。



== 容量情報を表示

*システム* ページからオンプレミスのONTAPクラスターを選択すると、*システムの詳細* ページに、合計容量、使用容量、使用可能な容量など、クラスターの容量情報が表示されます。



== ライセンスと契約の詳細を表示する

*サブスクリプションとライセンス* ページから、オンプレミスの各ONTAPクラスターの契約の詳細を表示できます。

https://docs.netapp.com/us-en/bluexp-digital-wallet/task-manage-on-prem-clusters.html["コンソールからオンプレミスのONTAPクラスタのライセンスを管理する方法の詳細"^]
